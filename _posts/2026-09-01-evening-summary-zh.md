### [Google 从 Chrome 商店移除 MV2 扩展包括 uBlock Origin](https://webiterate.dev/google-removed-extensions-ublock-origin-108/) ⭐️ 7.0/10

Google 已从 Chrome 网上商店中移除了所有 Manifest V2（MV2）扩展程序，包括广受欢迎的广告拦截工具 uBlock Origin。此举是 Google 推动扩展生态系统从 MV2 向 Manifest V3（MV3）迁移的既定策略的一部分。MV3 对扩展程序可使用的 API 施加了更多限制，特别是限制了静态规则集的大小和动态更新能力，这直接影响了广告拦截器的过滤效果。社区对此反应强烈，多位用户表示已转向 Firefox 或表示将继续使用 Firefox 直到最后一刻，部分用户指出 uBlock Origin 在 Firefox 上原本就有更好的表现。

hackernews · twapi · 8月31日 21:10 · [社区讨论](https://news.ycombinator.com/item?id=49514878)

**「背景」** Manifest V2 是 Chrome 扩展程序长期使用的旧版 API 架构，而 Manifest V3 是 Google 在 2019 年提出的新一代标准。MV3 的核心变化包括将 declarativeNetRequest API 替换原有的 webRequest API，并对规则数量设置了更严格的限制。这些变化对广告拦截扩展的运作方式产生了根本性影响，因为拦截器需要实时更新过滤规则来应对新型广告和追踪器。

**「影响」** Chrome 用户将失去通过官方商店获取 MV2 版本 uBlock Origin 的途径，可能面临广告拦截能力下降或需要寻找替代方案的风险。对于依赖广告拦截保护家中非技术型用户（如年迈父母）的用户而言，这一变化尤为敏感，因为恶意广告仍然是传播诈骗软件和流氓程序的主要渠道之一。

**「社区讨论」** 社区反馈呈现明显的一边倒态势。多位评论者表达了对此变化的不满，并宣布已迁移至 Firefox 或将继续使用 Firefox 直至其终结。有用户明确指出 uBlock Origin 在 Firefox 上的运行效果更佳，并建议尚未迁移的用户考虑转向 Firefox。部分用户将此问题上升至对 Google 在互联网上拥有&quot;绝对控制权&quot;的更深层担忧。

**标签**: `#Chrome扩展移除`, `#MV2到MV3迁移`, `#广告拦截器`, `#浏览器生态`, `#谷歌政策变化`
